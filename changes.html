What the rebase changed

The port had two goals: move onto current main, and stop introducing a bespoke feature flag. The second turned out to shrink the footprint far more than expected, because main had meanwhile grown both a features.beta flag and a beta crate whose code is explicitly exempt from stability review.

The beta-crate domain module · 10 files, 5,500 lines

cli/beta/src/extensions/ — all domain logic. It lives here rather than in flox-rust-sdk on the instruction of the repo's own adding-beta-subcommand skill, which states that changes outside cli/beta "require more thorough review which will make it slower to add the beta command."

Relocating it cost almost nothing: across 5,500 lines the module had only three crate:: imports — Flox twice and the git provider once — both public flox-rust-sdk API. Rewriting three import lines and moving six dependencies between two manifests bought a completely untouched SDK.

source.rs is still one line. The ExtensionSource trait — the abstraction meant to let FloxHub become a second source without breaking changes — was never written, and floxhub.rs was never created. That was a stated v1 goal, and the port carried the gap forward unchanged rather than closing it.

Consequence is bounded but not free: state.toml records a source (a URL or local path) and a kind, so an installed extension's origin is at least recoverable. But source is not a clean github-vs-floxhub discriminant — it holds the raw URL/path, and kind distinguishes script/git/binary/local, not the remote. Adding FloxHub means extracting an abstraction from working code rather than filling a prepared slot, and likely a state-shape decision too.

Deliberate wiring · 7 pre-existing files, +44 lines

Everything above could be deleted without flox noticing. These seven edits are what make the new code reachable, and therefore the only places a regression can originate.

cli/flox/src/main.rs

+6 / −0 · the highest-leverage change in the branch

The binary's entry point. The ParseFailure::Stderr arm is what prints "unknown command" errors and exits non-zero.

cli/flox/src/main.rs
             bpaf::ParseFailure::Stderr(m) => {
+                // `flox <name>` may be an installed beta extension rather than a
+                // typo. Only reached once the parse has already failed, and a
+                // miss falls through to the unchanged error below.
+                if let Some(exit) = commands::extension::try_dispatch_external() {
+                    return exit;
+                }
                 message::error(format!("{m:80}"));
                 return ExitCode::from(1);
             },

Impact and architecture

Placement is the whole design. The hook sits inside the failure arm, so no extension code runs on any invocation that parses. A miss falls through to the identical error flox would have printed anyway, which is what Option buys.

It is also where residual risk concentrates: these lines run on every failed parse of every flox command, for every user, installed extensions or not. That is the entire blast radius, and it is six lines wide.

Impact and architecture

Beta is a flattening group — the variant on Commands carries no command attribute, so its members declare their own. Joining it therefore keeps the invocation as flox extension install while hiding it from --help.

hide is required on the variant itself; the enum-level attribute alone is not sufficient, and the skill calls this out explicitly. It also replaces five per-handler feature checks that v1 needed, because the group gates once before dispatching.

What the shape of this diff proves, and what it does not

What it proves

The isolation claim is measurable. Seven files of wiring, 44 added lines, zero hand-written deletions, and an untouched flox-rust-sdk. Reverting is mechanically simple: delete two directories and four files, revert seven small edits. Nothing was refactored on the way past.

What it does not prove

A small diff is not a safe diff. The six lines in main.rs execute on every failed parse for every user. Line count measures reviewability, not risk — those six deserve more scrutiny per line than the 2,429-line manager.rs, which cannot run unless someone invokes it.

Before reading the branch

Nothing here is committed. The entire port sits as working-tree changes in a worktree at ../flox-gh-plugin-extension-v2. just format has not been run, and PROJECTS.md still has open checkboxes for the verification tasks.
